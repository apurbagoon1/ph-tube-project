## 📺 PH Tube

PH Tube is a dynamic and interactive video browsing web application built with vanilla JavaScript, Tailwind CSS, and DaisyUI. The app fetches categorized video data from the Programming Hero API, allowing users to explore videos by category, search by title, and view detailed information for each video.

## 📋 Features

- Fetch and display video categories dynamically from an API.
- Load and filter videos by category or search query.
- Highlight active category buttons for better UI feedback.
- Responsive grid layout for video cards using Tailwind CSS.
- Detailed video modal popup showing thumbnail, title, and description.
- Loading spinner for better UX during API calls.
- Clean and modern UI styled with Tailwind CSS and DaisyUI.
- Easy to extend and customize.

---

## 🛠️ Technologies Used

- **HTML5** & **CSS3**
- **JavaScript (Vanilla)**
- **Tailwind CSS** for utility-first styling
- **DaisyUI** component library built on Tailwind
- **Programming Hero API** for video data

   cd ph-tube
